# ASCET Copilot

ASCET Copilot package bundle for Pi.

## Install

Install the official Pi agent first:

```powershell
npm install -g @earendil-works/pi-coding-agent
```

Then install ASCET Copilot:

```powershell
pi install npm:@zeerke/ascet-copilot
pi
```

This bundle loads the ASCET tool extension, ASCET startup UI, subagents, todo overlay, ask-user-question, Hermes memory, Plannotator, and web access package resources.

## Update

```powershell
pi update --extension npm:@zeerke/ascet-copilot
```

## Remove

```powershell
pi remove npm:@zeerke/ascet-copilot
```
