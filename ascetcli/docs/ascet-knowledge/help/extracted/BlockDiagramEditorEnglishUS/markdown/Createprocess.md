# Creating a Process

To create a process, proceed as follows:

1. Activate the Outline pane.
1. Select a public diagram.
1. In the Insert menu, select Process
1. click the ![](images/button_insertprocess.gif) button.
1. Enter a name for the process and press Enter.

You can move, rename or delete processes the same way as methods.

As a process does not have any arguments, only the Locals tab and the Local Variable menu (see [Adding Local Variables to the Method or Process](BDE_Localvariables.md)) are available in the Signature Editor.
