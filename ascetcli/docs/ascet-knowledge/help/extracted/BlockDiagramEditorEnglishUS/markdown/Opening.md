# Opening the Block Diagram Editor

To open the block diagram editor, proceed as follows:

1. In the Component Manager, select the desired item.
1. Double-click on the item
1. In the Edit menu, select Open Component
1. Select Open Component from the context menu
1. Press Enter.

The selected item opens in the block diagram editor.

When you open a component that exceeds the currently selected size of the drawing area (see [Setting the Size of the Drawing Area](BDE_Setting_the_Size_of_the_Drawing_Area.md)), a message window opens. It displays the size of the drawing area and the size of the component, and offers the possibility to adjust the former.
