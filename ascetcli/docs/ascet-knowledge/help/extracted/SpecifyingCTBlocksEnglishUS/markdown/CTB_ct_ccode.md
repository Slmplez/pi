# Continuous Time Blocks as C Code

The considerations applying CT blocks as block diagrams are valid for CT blocks as C code too, i.e. everything works in the same way as for classes, except for the points listed above. One difference between continuous time blocks specified as block diagrams and as C code is that the basic elements that can be defined are different. CT blocks in C code are discussed in [Overview - Modeling in C](CTB_Overview_Modeling_in_C.md).

CT blocks specified as C code are used mainly to specify basic components for a process model. The differential equations used to model these components can be specified more quickly and concisely in code than in a block diagram.
