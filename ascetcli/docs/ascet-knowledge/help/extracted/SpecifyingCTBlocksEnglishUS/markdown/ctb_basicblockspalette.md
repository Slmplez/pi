# Basic Blocks Palette

This palette is available only in the block diagram editor for CT blocks.

The palette contains following functions:

| Column 1 | Column 2 |
| --- | --- |
|  | Combo box to select the number of operator inputs |
|  | Addition |
|  | Subtraction |
|  | Multiplication |
|  | Division |
|  | Hierarchy |
|  | Comment |
