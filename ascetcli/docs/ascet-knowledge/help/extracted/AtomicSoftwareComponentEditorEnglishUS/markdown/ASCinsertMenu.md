# Insert Menu

The menu Insert contains the following functions:

Component

Inserts a component as a complex element.

Method

Creates a method.

Runnable

Creates a runnable.

Diagram

Creates a new diagram.

| Column 1 | Column 2 |
| --- | --- |
| Public | Contains only public methods. |
| Private | Contains only private methods. |
