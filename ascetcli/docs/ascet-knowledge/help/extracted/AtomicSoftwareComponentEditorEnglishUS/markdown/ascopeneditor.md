# Opening the Software Component Editor

To open the software component editor, proceed as follows:

1. In the Component Manager, select the desired software component.
1. Perform one of the following actions.

The selected item opens in the software component editor.

When you open an SWC that exceeds the currently selected size of the drawing area (see [Setting the Size of the Drawing Area](ascsetsizedrawingarea.md)), a message window opens. It displays the size of the drawing area and the size of the component, and offers the possibility to adjust the former.
