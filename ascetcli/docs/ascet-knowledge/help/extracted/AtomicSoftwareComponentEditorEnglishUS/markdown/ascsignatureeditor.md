# Signature Editors

This window can be opened with a double-click on a runnable or method in the Outline tab.

The signature editor for runnables contains the following elements.

- [Local Variable](asclocalvariablemenu.md) menu
- [Locals](asclocalstab.md) tab
- [Settings](ASCSettingsTab.md) tab

The signature editor for methods contains a Settings tab with different content, and - in addition to the [Local Variable](asclocalvariablemenu.md) menu and [Locals](asclocalstab.md) Tab - the following elements.

- [Arguments](ascargumentsmenu.md) menu
- [Return](ascreturnmenu.md) menu
- [Arguments](ascargumentstab.md) tab
- [Return](ascreturntab.md) tab
- [Settings tab](BlockDiagramEditorEnglishUS.chm::/BDE_SettingsTab.htm)

Both signature editors contain the following buttons:

![](BUTTON.GIF) OK

Closes the signature editor and accepts the settings.

![](BUTTON.GIF) Cancel

Closes the signature editor without accepting the settings.
