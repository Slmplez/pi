# Creating an Exclusive Area

To create an exclusive area, proceed as follows.

1. In the Elements palette, click on the ![](buttonResource.gif) Resource button.
1. Place the resource in the drawing area.
1. Edit the Reserve and Release methods [manually](ASCEditSequence.md) or [automatically](ASCassignindividual.md).
1. [Use the exclusive area](ASCusingExclusiveAreas.md).
