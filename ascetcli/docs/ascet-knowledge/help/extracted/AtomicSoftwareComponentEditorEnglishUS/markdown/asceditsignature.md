# Editing the Signature of a Runnable or Method

To edit the signature of a runnable or method, proceed as follows:

1. In the Outline tab, select the name of the runnable or method you want to modify.
1. Do one of the following:
1. Define the arguments and return value for the method as described in [Adding an Argument to the Method](ascaddargument.md) and [Adding a Return Value to the Method](ascaddreturnvalue.md).
1. Define local variables for the runnable or method as described in [Adding Local Variables to a Runnable or Method](ASCaddLocalvariables.md).
1. Click OK to close the signature editor.
