# The Measurement System

The measurement system offers a variety of ways of displaying the values of elements:

- [Oscilloscope](oscilloscope.md)
- [Numerical Display](numerical_display.md)
- [Horizontal and Vertical Bar Display](horizontal_vertical_bar_display.md)
- [Bit Display](bit_display.md)
- [Recorder](recorder.md)

The measurement windows can display measurements of the values for any element during an experiment in ASCET. All measurement windows are opened by assigning elements to them from the experimentation environment; see [Assigning an Element to a New Measurement Window](assign_element_measurement.md). A measurement channel is created for each measured element, and it is also possible to create several measurement channels for one element, if it is displayed in two different measurement windows. It is also possible to display measurement data without saving it, to display it and simultaneously start and stop recording or to record data without previously displaying it.

Each measurement window has to be set up with the values it is to show. The displays offer a variety of customizing options which can be adjusted during setup of the experiment, but also while it is running. If a calculation with real values results in a non-regular value of Inf or NaN (e.g. division by a very small number, dividing 0 by 0, etc.), that non-regular value is displayed in the numerical or bar display and (for block diagrams) in element monitors. In addition, an error message is displayed in the ASCET monitor window.

Offline experimentation is not real-time, whereas online experimentation always is.
