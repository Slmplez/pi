# Experiment Menu (Offline Experiment)

These menu options are only available in offline experiments.

This menu contains the following options:

Automatic Stop (for Signals)

Stops the experiment automatically when the end of the stimulating signal is reached [(Setting up the Automatic Stop)](setup_automatic_stop.md).

Stop Experiment (F6)

Stops the experiment.

Start Experiment (F7)

Starts the experiment.

Pause Experiment (F8)

The experiment is paused.

Step Experiment (Shift + F7)

The experiment is performed in step mode.

See also

[Setting up the Automatic Stop](setup_automatic_stop.md)
