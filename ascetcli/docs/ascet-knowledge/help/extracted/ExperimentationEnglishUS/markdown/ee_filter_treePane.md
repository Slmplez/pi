# Filtering the Tree Pane

The Outline and Navigation tabs can be filtered. To do so, proceed as follows.

##### Outline tab

1. Click on the ![](button_ElementsHierarchical.gif) button to switch to the default hierarchical view.

This is the only way to display diagrams, methods and processes.

1. Click on the ![](button_ElementsFlat.gif) button display the elements of the component in a flat structure.
1. Click on the ![](button_ExportedElements.gif) button to display only exported elements.
1. Click on the ![](button_contpar.gif) button to display only parameters.

##### Navigation tab

1. In the tab you want to filter, click on the ![](images/button_filtertab.gif) button.

The ASCET Options window opens in the Navigation Tree node.

1. In the Navigation Tree node, activate the options of the items you want to display in the tab.
1. Click OK to close the ASCET Options window.

Only items with activated options are shown in the tab. The button is marked with a green symbol to indicate an active filter: ![](images/button_filtertab2.gif)

The filter settings made here affect all component editors.
