# Adding Basic Elements, Enumerations

To add basic elements or enumerations, proceed as follows:

1. In the Elements palette or toolbar, click on the button for the element you want to create (![](buttonVariableC.gif)![](buttonVariableL.gif)![](buttonVariableI.gif)![](buttonVariableW.gif)(![](buttonVariableS.gif)![](buttonVariableU.gif))![](buttonVariableE.gif)).
1. Enter a name for the element and press Return.

Element names must not begin with a number. If you enter a name that begins with a number, an allowed name is suggested instead.

By default, the ![](buttonVariableI.gif)![](buttonVariableW.gif) buttons are displayed. To display the ![](buttonVariableS.gif)![](buttonVariableU.gif) buttons instead, the [editor option](ComponentManagerEnglishUS.chm::/cm_options_for_editors.htm) Use signed/unsigned discrete types must be activated.
