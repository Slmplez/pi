# Specification View

The Specification view contains the following elements:

- table field

This field contains the conditional table. The columns contain conditions and instructions, the rows contain conditions.

You can [set the background colors](Setting_the_Background_Color.md) in the condition and instruction areas.

The table field offers a [context menu](ctab_contextmenu_specificationview.md).
