# Committing

When you have completed your edits for an item, you can select [Commit](SCM_ASCET-SCM_Menu.md#Commit) or [Add and Commit](SCM_ASCET-SCM_Menu.md#Add_and_Commit) to take this item out of the "locked" state and to save the current state of this item in the repository. This is equivalent to "checking in" the item.

- Commit serves for storing a new version of an existing item (that is already under version control) in the Subversion repository.
- Add and Commit brings the selected item under version control and commits it to the Subversion repository in a single operation.
