# Updating Items to Latest Revision

Proceed as follows to update items to the latest revision number:

1. In the ASCET component manager, select the items you want to update.
1. In the SCM menu, select Update to Latest Revision.
1. Close the Update to Latest dialog box.

If you select a folder in ASCET, the Update to Latest Revision command does not search for items in the same folder that exist in the repository but not yet in the ASCET database/workspace. To retrieve "new" items, use the [Checkout](SCM_ASCET-SCM_Menu.md#Checkout) command.
