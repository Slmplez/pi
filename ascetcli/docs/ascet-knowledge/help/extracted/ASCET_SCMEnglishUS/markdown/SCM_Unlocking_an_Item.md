# Unlocking an Item

Note that any locked item will be unlocked automatically when you [Commit](SCM_ASCET-SCM_Menu.md#Commit) the item.

Proceed as follows to unlock an item manually:

1. In the ASCET component manager, select the currently locked items you want to unlock.
1. In the [SCM](SCM_ASCET-SCM_Menu.md) menu, point to [Additional Commands](SCM_ASCET-SCM_Menu.md#Additional_Commands) and select Release Lock.
1. Close the Unlock: Results dialog box.
