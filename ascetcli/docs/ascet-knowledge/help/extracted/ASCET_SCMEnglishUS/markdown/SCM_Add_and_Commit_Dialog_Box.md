# Add and Commit Dialog Box

This dialog box enables you to bring the selected items under version control and to commit these items. It can be displayed via the [Add and Commit](SCM_ASCET-SCM_Menu.md#Add_and_Commit) command in the [SCM](SCM_ASCET-SCM_Menu.md) menu.

Note that the "commit" part of this operation is the same that is provided by the Commit dialog box.
