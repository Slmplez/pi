# Selecting or Creating a Repository Folder for an Item

Proceed as follows to select or create a repository folder (within the [selected repository](SCM_Selecting_a_Repository.md)) for an item that is not yet under version control in Subversion:

1. In the ASCET component manager, select the item for which you want to create a new repository folder.
1. In the [SCM menu](SCM_ASCET-SCM_Menu.md), select [Add and Commit](SCM_ASCET-SCM_Menu.md#Add_and_Commit).

The [Add and Commit Dialog Box](SCM_Add_and_Commit_Dialog_Box.md) is displayed.

1. In this dialog box, right-click the item to display the [Context Menu for Added Items](SCM_Context_Menu_for_Added_Items.md).
1. Select Change Folder from this context menu.

The [Repository Selection Dialog Box](SCM_Repository_Selection_Dialog_Box.md) is displayed.

1. In this dialog box, either select a folder or click New Folder and specify the new folder name.
1. Click OK to return to the Add and Commit dialog box.
1. Click Finish to complete the operation.
1. The folder you select or specify in this way applies to the SCM path of the item but does not affect its ASCET path.
