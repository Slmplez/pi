# Editing Items in Offline Mode

Proceed as follows to edit items in offline mode (i.e. while you do not have access to the selected Subversion repository URL, e.g. during field tests):

1. In the [SCM](SCM_ASCET-SCM_Menu.md) menu, select Edit without Lock.
1. Edit the selected items.
1. When the Subversion repository URL (i.e. the server on which the Subversion repository runs) is available to you again, select [Connect to Repository](SCM_ASCET-SCM_Menu.md#Connect_to_Repository1).
1. Then open the [SCM](SCM_ASCET-SCM_Menu.md) menu, point to [Additional Commands](SCM_ASCET-SCM_Menu.md#Additional_Commands) and select Commit New Revision without Lock.
