# Context Menu for Selected Items

This menu is displayed when you right-click a selected item, e.g. on the Step 2 of 4 page of the Checkout Dialog Box.

##### Show Details

Displays the [Details of <Item Name> Dialog Box](SCM_Version_Details_Dialog_Box.md) for the selected item.

##### Change Revision

Displays the [Select Revision Dialog Box](SCM_Select_Revision_Dialog_Box.md) which enables you to select a different version of the selected item.

##### Delete Selection

Deletes the selected item from the [Checkout Dialog Box](SCM_Checkout_Dialog_Box.md).
