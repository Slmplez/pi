# Locking an Item

Proceed as follows to lock an item:

1. In the ASCET component manager, select the items you want to lock.
1. In the [SCM](SCM_ASCET-SCM_Menu.md) menu, select Get Lock.
1. Close the Lock: Results dialog box.

Note that the item will be unlocked automatically when you [commit](SCM_Committing_an_Item.md) the item. Alternatively, you can [unlock](SCM_Unlocking_an_Item.md) the item manually.
