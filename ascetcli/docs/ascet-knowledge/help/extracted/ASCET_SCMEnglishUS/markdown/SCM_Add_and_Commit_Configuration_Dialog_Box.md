# Add and Commit Configuration Dialog Box (Advanced Mode)

This dialog box is displayed when you open the [SCM menu](SCM_ASCET-SCM_Menu.md), point to [Configuration Management](SCM_ASCET-SCM_Menu.md#Configuration_Management) and select Add and Commit Configuration.

This dialog box enables you to bring the selected configurations under version control and to commit these configurations.

Note that the "commit" part of this operation is the same that is provided by the [Commit Configuration Dialog Box](SCM_Commit_Configuration_Dialog_Box.md).
