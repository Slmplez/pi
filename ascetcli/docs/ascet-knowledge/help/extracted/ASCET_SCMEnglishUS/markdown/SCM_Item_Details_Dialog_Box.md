# Item Details Dialog Box

This dialog box is displayed when you click on the Element Data button in the [Details of <Item Name> dialog box (Advanced Mode)](SCM_Version_Details_Dialog_Box.md)or double-click on an item in the Selected Elements pane on the Step 1 of 4 page of the [Checkout (Advanced Mode)](SCM_Checkout_Dialog_Box.md) dialog box.

It displays the following information for the item:

- The element name of this item in the [repository](SCM_Repository.md).
- The element name of this item in ASCET.
- The ASCET path of this item.
- The current ASCET export version associated with this item.
