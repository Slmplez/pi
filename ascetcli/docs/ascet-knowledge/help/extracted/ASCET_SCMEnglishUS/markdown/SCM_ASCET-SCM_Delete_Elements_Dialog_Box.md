# ASCET-SCM Remove Dialog Box

This dialog box is displayed when you open the [SCM menu](SCM_ASCET-SCM_Menu.md), point to [Additional Commands](SCM_ASCET-SCM_Menu.md#Additional_Commands) and select Delete.

If you click Yes to confirm the deletion, all items that will be deleted are listed, with version details, in the [Remove dialog box](SCM_Delete_Dialog_Box.md).
