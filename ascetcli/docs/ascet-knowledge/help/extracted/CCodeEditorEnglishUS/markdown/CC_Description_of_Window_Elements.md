# C Code Editor - Window Elements

The C code editor window contains the following window elements:

- [Menu Bar](CC_menu_bar.md)
- Toolbars
- [General](CC_Toolbar_General.md) toolbar
- [Elements](CC_Toolbar_Elements.md) toolbar

- [Tree](cc_componentpane.md) pane

This pane lists all elements of the component.

- Outline tab
- Navigation tab
- Database/Workspace tab
- [Elements](CC_Elements_Palette.md) palette

- [Library](CC_Library_Palette.md) palette

- [Specification](CC_Specification_View.md) View
- [Search Results View](CC_SearchResultsView.md)
- [Browse](CC_Browse_View.md) View
- [External Editor View](CC_External_Editor_View.md)

This view is used for component specification via an external editor. It is opened with the ![](buttonactivateexternaleditor.gif) button in the General toolbar.

- status bar

The status bar contains information on the element currently selected in the Outline tab (if the Mouse Over option on the [Editors](ComponentManagerEnglishUS.chm::/cm_options_for_editors.htm) node of the ASCET options is deactivated) or on the element in the Outline tab the mouse is currently placed on (if the Mouse Over option is activated).
