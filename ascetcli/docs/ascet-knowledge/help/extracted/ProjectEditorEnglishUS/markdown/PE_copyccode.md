# Copying the C Code for an Entire Project

When editing a project that was written for a different target, the C code and operating system (see [Copying Operating System Settings](copyos.md)) settings may be copied from the other target, experiment type, or implementation.

To copy the C code for all classes and modules of a project from another target, experiment type, or implementation, proceed as follows:

1. In the project editor, select the appropriate target and code generation options for your target, as described on [Adjusting the Code Generation Settings for a Project](adjustcode_gen.md).
1. In the Extras menu, select Copy C Code From.

The Selection Required window opens.

1. Select the target you want to copy the code from, and click OK.

The target code is copied to your target.
