# Project

In ASCET, an embedded software system is defined in the context of a project. [Transformation formulas](PE_TransformationFormulas.md), [implementation types](PE_ImplementationTypes.md) and [imported elements](ElementEditorEnglishUS.chm::/EEd_ImportedElements.htm) are resolved only in the context of a project. A project contains at least the following:

- A collection of modules
- The task schedule for the real-time operating system
- The definition of the inter-process communication

The central part of a project is the definition of the operating system’s task schedule. Here, the dynamic behavior of the system is described. The figure illustrates the structure of a project.
