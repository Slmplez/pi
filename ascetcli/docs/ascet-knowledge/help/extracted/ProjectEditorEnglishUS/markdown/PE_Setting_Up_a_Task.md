# Setting Up a Task

Several properties can be set for a task. Proceed as follows:

1. In the project editor, open the OS tab.
1. [Select a task type.](triggermode.md)
1. [Assign a priority.](PE_priority.md)
1. Define the scheduling
1. For interrupt tasks only: [Select a trigger (ISR source)](PE_trigger.md).
1. [Set the Autostart option.](setautostart.md)
1. [Set the deadline and minimum period.](setdeadline.md)
1. [Set up hook routines.](HookRoutine.md)
