# Notes Editor Window

The notes editor window contains the following elements:

- [Views](AD_ViewsMenu_NotesEditor.md) menu
- [Text Segments](AD_TextSegmentsMenu.md) menu
- [Edit](AD_EditMenu_NotesEditor.md) menu
- Views list

Lists the available views.

- Text Segments list

Lists the available text segments.

- ![](BUTTON.GIF) >> and <<

>> assigns a selected view to a selected text segment. << deassigns a selected view from a text segment.

- edit field for text segments

Used to enter the content of a selected text segment.

- You can
- [Create a Text Segment](create_text_segment.md)
- [Edit a Text Segment](edit_text_segment.md)
- [Assign a Text Segment to a View](assign_text_segment.md)
- [Deassign a View](deassign_view.md)
- [View Text Segment Assignments](view_text_segment_assignments.md)
