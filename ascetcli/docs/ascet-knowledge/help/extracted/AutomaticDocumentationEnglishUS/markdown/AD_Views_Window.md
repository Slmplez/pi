# Views Window

This window contains the following elements.

- views list

A list of all available views.

![](BUTTON.GIF) Export

Exports selected views in an XML file, see [Exporting Views](Exporting_Views.md).

![](BUTTON.GIF) Import

Imports views, see [Importing Views](Importing_Views.md).

![](BUTTON.GIF) Add

Creates a new view, see [Creating and Managing Views](AD_create_docu_views.md)

![](BUTTON.GIF) Rename

Renames a selected view, see [Creating and Managing Views](AD_create_docu_views.md).

![](BUTTON.GIF) Edit

Edits the properties of a selected view, see [Editing a View](determine_content_docu_file.md).

![](BUTTON.GIF) Delete

Deletes selected views, see [Creating and Managing Views](AD_create_docu_views.md).

![](BUTTON.GIF) Default

Makes the selected view the default view, see [Selecting a Default View](select_default_view.md).
