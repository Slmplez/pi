# Creating an Icon

To create a new icon, proceed as follows:

1. In the Component Manager, select the folder where you want to add the new icon.
1. Do one of the following:
1. [Start the icon editor](SI_start_icon_editor.md).
1. [Load a bitmap](SI_load_icon.md).
1. [Scale the icon](SI_scale_icon.md).
