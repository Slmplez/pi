# Method: DatabasePath

##### Name

DatabasePath

##### Description

Answer a string containing the file system location of the current used database. Return an error in case of: - No database is open.

##### Returns

A value of type string.

##### Example

DatabasePath()

##### Remarks

API-Result-Codes: 1004 No database.
