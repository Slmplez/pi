# Method: IsExperimentOpen

##### Name

IsExperimentOpen

##### Description

Lookup for an open experiment. Return an error in case of: - No open experiment available

##### Returns

A value of type string.

##### Example

IsExperimentOpen()

##### Remarks

API-Result-Codes: 0 1009 No open experiment found.
