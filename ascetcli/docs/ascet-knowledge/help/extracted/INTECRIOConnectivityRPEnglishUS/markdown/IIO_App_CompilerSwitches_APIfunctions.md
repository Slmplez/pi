# Appendix: Compiler Switches and API Functions

This annex contains remarks to target-specific external C code ([Compiler Switches for External C Code](IIO_CompilerSwitches_ExternalCcode.md)), as well as the API functions ASCET provides for the ES113x experimental target. These functions define the interfaces between ASCET and the following applications:

- [ERCOSEK](IIO_APIfunctionsERCOSEK.md)
- [NVRAM](IIO_APIfunctionsNVRAM.md)
- [Watchdog](IIO_APIfunctionsWatchdog.md)
- [ES1135 LEDs](IIO_APIfunctionsES1135LEDs.md)
- [Miscellaneous](IIO_APIfunctionsMiscellaneous.md)

All API functions are described according to the same [Description Structure for API Functions](IIO_DescriptionStructure_APIfunctions.md).
