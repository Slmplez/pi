# NVRAM Cockpit

The NVRAM API (see [API Functions - NVRAM](IIO_APIfunctionsNVRAM.md)) offers several functionalities to control the NVRAM update. During experiment, these functionalities are available in a special window, the NVRAM cockpit. Changes applied via the API functions are transferred to the NVRAM cockpit, too.
