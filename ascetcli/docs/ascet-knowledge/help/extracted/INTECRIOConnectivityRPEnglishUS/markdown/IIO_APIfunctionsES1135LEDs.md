# API Functions - ES1135 LEDs

The ES1135 Simulation Controller has three configurable LEDs. They are briefly described in [ES1135: LEDs](IIO_ES1135LEDs.md). The following interfaces to the LEDs are provided:

- [userLed<n>On](IIO_userLed_n_On.md)
- [userLed<n>Off](IIO_userLed_n_Off.md)
- [userLed<n>Toggle](IIO_userLed_n_Toggle.md)
