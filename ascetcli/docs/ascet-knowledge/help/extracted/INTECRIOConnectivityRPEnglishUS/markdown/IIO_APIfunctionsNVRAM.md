- [nvramEnableAutoUpdate](IIO_nvramEnableAutoUpdate.md)
- [nvramDisableAutoUpdate](IIO_nvramDisableAutoUpdate.md)
- [nvramCheckForAutoUpdate](IIO_nvramCheckForAutoUpdate.md)
- [nvramManualUpdateExit](IIO_nvramManualUpdateExit.md)
- [nvramManualUpdateBackground](IIO_nvramManualUpdateBackground.md)
- [nvramManualUpdateBlocked](IIO_nvramManualUpdateBlocked.md)

- [nvramGetUpdateAgeMs](IIO_nvramGetUpdateAgeMs.md)
