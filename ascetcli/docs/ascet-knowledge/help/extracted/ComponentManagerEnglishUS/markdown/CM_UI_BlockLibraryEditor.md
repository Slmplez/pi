# User Interface of the Block Library Editor

This window contains the following window elements:

- [File](CM_FileMenu_BlockLibrary.md) menu
- [Category](CM_CategoryMenu_BockLibrary.md) menu
- [Items](CM_ItemsMenu_BlockLibrary.md) menu
- [Toolbar](CM_Toolbar_BlockLibrary.md)
- Database or Workspace pane
- Block Library pane

- Categories list
- Items list
- preview field

This field shows the layout of the block library element selected in the Items list.
