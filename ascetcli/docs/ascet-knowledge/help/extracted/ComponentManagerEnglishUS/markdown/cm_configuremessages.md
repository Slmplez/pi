# Configuring Messages

The way messages are displayed in the Build tab of the ASCET monitor window can be configured. Some configurations are done directly in the Build tab:

1. [promoting information and warnings](to_promote_information_and_warnings.md) to warnings and errors and [revoking a promotion](To_Revoke_a_Promotion.md)
1. [hiding messages](Hiding_Messages.md) and [showing all hidden messages](Showing_all_Hidden_Messages.md)

Additional configuration possibilities are offered in the project-specific CodeGen Message Configuration window. This window can be accessed from the ASCET monitor window or from a project's Project Properties window. You can do the following:

1. [promote](Promoting_Information_and_Warnings.md) or [hide](Hiding_Messages_Monitor_Window.md) not only the messages currently displayed in the Build tab, but all existing messages,
1. [revoke promotions](Revoking_a_Promotion.md)
1. [show](Showing_Hidden_Messages.md) all or selected hidden messages

Unless specified otherwise, project-specific promotions are overridden by global configurations (see [Promoting Messages](CM_Promoting_Messages.md)).
