# Inserting a Folder or Item

To insert a folder or database/workspace item, proceed as follows:

1. In the Component Manager, select the target folder for the folder or item in the clipboard.
1. In the Edit menu, select Paste

or

1. Click on the ![](button_paste.gif) button

or

1. Press Ctrl + v.

The folder or item is inserted in the selected target folder. When the item was cut (see [Cutting a Folder or Item](CM_CutInsert.md)), the corresponding entry in the target folder is deleted.

[Cutting a Folder or Item](CM_CutInsert.md)
