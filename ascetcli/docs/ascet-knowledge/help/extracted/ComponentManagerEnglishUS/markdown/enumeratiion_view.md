# Selecting the Enumeration/Mode Group View

To select the enumeration/mode group view, proceed as follows:

- In the 1 Database or 1 Workspace list, select an enumeration or a mode group.

The enumerators or modes are listed in the 3 Contents field.

[Adding an Enumerator](add_enumerator.md), [Editing an Enumerator](rename_enumerator.md) and [Deleting an Enumerator](delete_enumerator.md) explain how to edit enumerations, and [Creating a Mode Group](SenderReceiverEditorEnglishUS.chm::/SREcreateModeGroup.htm) explains how to edit mode groups.
