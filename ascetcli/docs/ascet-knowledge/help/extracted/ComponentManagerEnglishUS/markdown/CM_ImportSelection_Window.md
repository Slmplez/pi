# Import Selection Window

This window is named Select Import File or Select Import Directory. It contains the following elements.

Import File / Import Folder field with ![](button_openfile.gif) / ![](button_openpath.gif) button

Contains path and filename of the file to be imported (entered directly or selected via the button).

![](BUTTON.GIF) Options

Opens/closes the Options field. This field contains the same options as the [Import](CM_Import_Node.md) node in the ASCET options window.

![](BUTTON.GIF) OK

Starts the import.

![](BUTTON.GIF) Cancel

Cancels the import.
