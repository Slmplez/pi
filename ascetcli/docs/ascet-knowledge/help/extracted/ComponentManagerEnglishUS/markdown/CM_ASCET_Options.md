# ASCET Options

ASCET offers the following windows to set options.

- [ASCET Options window](cm_user_interface_of_the_ascet_options_window.md)

for general and user-specific options

- [Project Properties window](ProjectEditorEnglishUS.chm::/PE_Settings_for_Window.htm)

for project-specific options

- ARXML Configuration Settings window

A window for the [configuration of AUTOSAR XML (*.arxml) code](AtomicSoftwareComponentEditorEnglishUS.chm::/ASCconfigureAUTOSARXMLOutput.htm). The content of this window depends on the selected AUTOSAR version; for detailed information, see the descriptions in the ARXML Configuration Settings window.

- [Views window (Graphical Editors)](AutomaticDocumentationEnglishUS.chm::/AD_ViewsWindow_GraphicalEditors.htm)

used to edit the views for elements in all kinds of block diagrams, AUTOSAR SWC
