# Setting Up a ClientServer Interface

A ClientServer interface can contain several operations, each of which can be invoked separately.

1. [Open the ClientServer interface editor](SREopenSRIEditor.md).
1. Create an operation by doing one of the following:
1. Type in a name for the operation and press Enter.
1. [Edit the operation](SRE_EditOperation.md).
1. [Edit the operation return value](SRE_editOperationReturnValue.md).
1. [Implement the operation arguments](SRE_ImplementOperationArguments.md).
