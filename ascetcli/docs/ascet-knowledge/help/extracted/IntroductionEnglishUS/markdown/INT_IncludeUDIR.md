# Including User-Defined Interpolation Routines

Including [user-defined interpolation routines](INT_UserDefinedInterpolationRoutines.md) consists of the following steps.

1. Creating the interpolation routine, either as C code class in ASCET or as header file and object library
1. [Creating an option set for the interpolation routine](INT_CreateOptionSet_UDIR.md)
1. [Mapping the ASCET interpolation routines to function names in the interpolation routine](INT_CreateMapping_UDIR.md)
