# External Editor View

The external editor view contains the following elements:

- selection field

This field lists all methods/processes in the component. You select the one you want to edit. The process/method currently edited in the external editor is marked with the ![](icon_InExternalEditor.gif) symbol, other processes/methods are marked with the ![](icon_NotInExternalEditor.gif) symbol.

- text field

This field is read-only. It shows the body code of the method/process selected in the selection field.

![](BUTTON.GIF) Start Edit

Opens the external editor.
