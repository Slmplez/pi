# Implementing Characteristic Lines/Maps

This instructions do not apply to characteristic lines/maps specified as explicit references. For that case, see [Implementing References](IED_ImplementingReferences.md).

To implement a characteristic line or map, proceed as follows:

1. Open the implementation editor for a characteristic line or map: [alternative A](IEd_open_impl_editor.md), [alternative B](IEd_open_impleditor_for_element.md), [alternative C](IEd_open_compo_project.md)
1. Select the tab for the implementation you want to edit.
1. Do one of the following:
1. Select another tab to edit the next implementation.
1. Click on OK to close the implementation editor.
