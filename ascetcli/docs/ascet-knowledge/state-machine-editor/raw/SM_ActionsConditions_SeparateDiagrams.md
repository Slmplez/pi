# Editing Actions/Conditions in Separate Diagrams

You have to perform the following steps to specify an action or condition in a separate diagram.

1. Create a [BDE diagram](SM_blockDiagram.md) or an [ESDL diagram](SM_Create_ESDL_Diagram_for_ActionsConditions.md) for actions/conditions.
1. [Add actions or conditions.](SM_add_condition.md)
1. [Open a diagram for actions/conditions](SM_opening_diagram.md) and specify actions or conditions.
1. [Activate/deactivate optimization of static actions.](To_Activate_Deactivate_Optimization_of_Static_Actions.md)
1. [Activate/Deactivate auto-inlining.](SM_To_Activate_Deactivate_Auto-Inlining.md)
