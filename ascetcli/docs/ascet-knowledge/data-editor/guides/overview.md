# Data Editor Overview

Start here to understand the editor at a high level before drilling into specific pages.

- [Overview](../raw/DEd_Overview.md)

  Note: When specifying a component, you can assign an initial value to each element in your specification. All of these values can be changed at a later stage. You can specify different data sets, i.e. sets of initialization values between which you can toggle, or you can change individual values during experimentation. This section describes the different editors for the various kinds of elements.
