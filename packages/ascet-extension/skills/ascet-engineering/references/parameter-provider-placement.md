# Parameter Provider Placement

Place a customer-only Provider in the verified Customer/Project owner layer. Place a China-shared functional parameter in a verified China Package or CNMS-owned Provider. Place a generic cross-region parameter in the corresponding Core Package Provider Class.

Place calibratable data in the Calibration Provider and fixed functional constants in the Constant Provider when live ownership evidence supports those classes. A Project or CNMS assembly path does not prove Provider ownership; resolve the canonical definition and active consumers.

Do not create, relocate, or select a generic Provider merely because one exists. Require shared semantic evidence, exact path/OID, compatible metadata, and a known business value/source. When ownership remains mixed or unclear, stop and resolve it before writing.
