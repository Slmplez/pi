# Parameter Provider Placement

Place a customer-only Provider in the verified Customer/Project owner layer. Place a cross-customer functional parameter in the corresponding Core Package Provider Class. Place calibratable data in the Calibration Provider and fixed functional constants in the Constant Provider when live ownership evidence supports those classes.

Do not create or select a generic Provider merely because one exists. Require cross-customer semantic evidence, exact path, compatible metadata, and a known business value/source.
