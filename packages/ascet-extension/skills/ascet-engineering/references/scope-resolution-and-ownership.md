# Scope Resolution and Ownership

Use `integrationScope` for Customer Project adaptation, Variant, Formula, assembly, customer mapping, scheduling, wrappers, and customer-only parameters. Analyze Customer Project → assembly/Formula → customer interface/wrapper → Package join point.

Use `featureScope` for Core Package algorithms, public interfaces, StateMachines, shared Parameters, and cross-customer defects. Analyze Package → Module/Class/Method/BDE/Provider → representative customer impact.

An exact Class path is a locator, not a scope conclusion. Determine owner role, requirement intent, affected layer, excluded objects, and editability from live evidence. Keep both candidates and ask the user when scope is ambiguous.
