# Project to ESDL and Signal Flow

Use this sequence: Project tree → Formula/assembly/Module instance → customer interface/wrapper → Package join point → Component references → BDE/diagram → signal source/transform/consumer → Method call → signature → complete ESDL body → relevant Elements → exact metadata → modification point.

`bde_edges=0` does not prove that no diagram exists. Do not call code reads on a BDE-only Component. Signal names alone do not establish identity or ownership.
