## Use This When

- The workflow is known but the semantic rule is still ambiguous.
- The task depends on vendor meaning rather than only runtime tool selection.
- The agent needs to know which extracted help package or editor guide to open next.

## Do Not Use This When

- The next tool is already obvious.
- The target is still fuzzy and has not been resolved.
- The task is only the automatic verification already returned by `ascet_edit`.
